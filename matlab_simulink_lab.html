Calculus of Phase Shifts, Phasor Vectors, and RLC Dynamics

An Interactive MATLAB & Simulink Engineering Laboratory

Author

Dr. Wesley Francillon, PhD

Papillon Engineering Curriculum Series • Interactive Laboratory Module

Bridging Calculus, Time-Domain Waveforms, Complex Phasors & Simulink

In traditional lectures, students memorize that current leads voltage by 90° in a capacitor (ICE) and lags by 90° in an inductor (ELI) without seeing how time-domain derivatives and integrals physically generate those shifts. This laboratory unifies analytical calculus, numerical MATLAB scripting, 2D vector geometry, and Simulink block-diagram simulation across RC, RL, and RLC networks.

1. Core Learning Objectives & Mathematical Competencies

By completing this laboratory, students master four interconnected pillars of electrical and dynamical systems engineering:

Pillar 1 • Time-Domain Calculus

Derivatives & Integrals in Circuits

Apply i_C(t) = C\dfrac{dv_C}{dt} and v_L(t) = L\dfrac{di_L}{dt} to prove why differentiating a sine wave (\dfrac{d}{dt}[\sin(\omega t)] = \omega\cos(\omega t)) produces an exact +90^\circ phase advance and scales peak amplitude by \omega.

Pillar 2 • Numerical Computation

MATLAB Discrete Differentiation

Build .m scripts from scratch using discrete time vectors, finite-difference numerical derivatives (diff(v_s) ./ diff(t)), and dual-axis oscilloscope waveform plots (yyaxis left and yyaxis right).

Pillar 3 • Frequency-Domain Vectors

Phasor Algebra & KVL Geometry

Transform differential operators into complex algebra (\dfrac{d}{dt} \leftrightarrow j\omega and \int dt \leftrightarrow \dfrac{1}{j\omega}) and verify Kirchhoff’s Voltage Law via polar (compass) and tip-to-tail (quiver) vector plots.

Pillar 4 • Dynamical Systems

Simulink Continuous Integrators

Translate 1st- and 2nd-order differential equations into continuous-time Simulink integrator feedback loops (\dfrac{1}{s}) to observe exponential charging and underdamped RLC ringing.

2. The Three Core Circuit Topologies Investigated

Throughout this laboratory, students analyze, code, and simulate three foundational circuit topologies across both the time domain (differential and integral calculus) and the frequency domain (complex phasor impedances):

CIRCUIT 1: SERIES RC 1st-Order Capacitive
  • Derivative Law: i_C(t) = C\dfrac{dv_C(t)}{dt}
  • Integral Law: v_C(t) = \dfrac{1}{C}\displaystyle\int i_C(t)\,dt
  • Phasor Impedance: \mathbf{Z}_C = \dfrac{1}{j\omega C} = -jX_C
  • Phase Shift: \mathbf{I} leads \mathbf{V}_C by +90^\circ (ICE)
CIRCUIT 2: SERIES RL 1st-Order Inductive
  • Derivative Law: v_L(t) = L\dfrac{di_L(t)}{dt}
  • Integral Law: i_L(t) = \dfrac{1}{L}\displaystyle\int v_L(t)\,dt
  • Phasor Impedance: \mathbf{Z}_L = j\omega L = +jX_L
  • Phase Shift: \mathbf{V}_L leads \mathbf{I} by +90^\circ (ELI)
CIRCUIT 3: SERIES RLC 2nd-Order Resonant
  • KVL Loop: L\dfrac{di}{dt} + Ri + \dfrac{1}{C}\displaystyle\int i\,dt = V_s
  • 2nd-Order ODE: LC\dfrac{d^2v_C}{dt^2} + RC\dfrac{dv_C}{dt} + v_C = V_s
  • Roots: s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}
  • Regimes: Underdamped, Critical, Overdamped

3. Part I: The Calculus of Sine Waves & Time-Domain Derivatives in MATLAB

Why Differentiating a Sine Wave Produces a +90^\circ Phase Shift

In an ideal resistor, voltage and current are proportional (v_R = i_R R), so their waveforms peak and cross zero at the exact same instant. In reactive components, however, voltage and current are linked by calculus:

\text{Capacitor: } i_C(t) = C \frac{dv_C(t)}{dt} \qquad \Bigg| \qquad \text{Inductor: } v_L(t) = L \frac{di_L(t)}{dt}

When we drive a capacitor with a sinusoidal voltage v_C(t) = V_m \sin(\omega t), the chain rule of calculus gives:

i_C(t) = C \frac{d}{dt}\Big[V_m \sin(\omega t)\Big] = \underbrace{\omega C V_m}_{I_m} \cos(\omega t) = I_m \sin(\omega t + 90^\circ)

GEOMETRIC PROOF: HOW THE DERIVATIVE SLOPE (dv_C/dt) CREATES A +90° LEADING CURRENT WAVE

How MATLAB Computes a Numerical Derivative (diff)

In digital oscilloscopes and MATLAB scripts, continuous waveforms are stored as discrete vectors sampled every \Delta t seconds. MATLAB’s diff(v_s) command subtracts each voltage sample from the next (v_{k+1} - v_k). Dividing element-by-element (./) by diff(t) computes the instantaneous rise-over-run derivative slope at every microsecond:

\frac{dv}{dt} \approx \frac{\Delta v}{\Delta t} = \frac{v(t_{k+1}) - v(t_k)}{t_{k+1} - t_k}

% =========================================================================
% PART 1A: NUMERICAL TIME DERIVATIVE OF A CAPACITOR IN MATLAB
% =========================================================================
clc; clear; close all;

% 1. Create a time vector from 0 to 0.05 s (3 cycles of 60 Hz) in 10 us steps
t = 0 : 1e-5 : 0.05;

% 2. Define the 60 Hz sinusoidal voltage: v_s(t) = 12*sin(2*pi*60*t)
f = 60;                         % Frequency = 60 Hz
w = 2 * pi * f;                 % Angular frequency = 376.99 rad/s
v_s = 12 * sin(w * t);          % Applied capacitor voltage [Volts]

% 3. Compute the numerical time derivative dv_s / dt
dv_dt = diff(v_s) ./ diff(t);   % Rise-over-run slope [Volts/sec]
t_diff = t(1:end-1);            % Trim last time point to match diff() length

% 4. Apply Capacitor Calculus Law: i_C(t) = C * (dv_s / dt)
C = 10e-6;                      % Capacitance = 10 uF
i_C = C * dv_dt;                % Resulting capacitor current [Amps]

% 5. Dual-Axis Oscilloscope Plot
figure(1);
yyaxis left;
plot(t, v_s, 'b-', 'LineWidth', 2);
ylabel('Capacitor Voltage v_C(t) [Volts]'); ylim([-15, 15]);

yyaxis right;
plot(t_diff, i_C, 'r--', 'LineWidth', 2);
ylabel('Capacitor Current i_C(t) [Amps]'); ylim([-0.06, 0.06]);
xlabel('Time t [seconds]');
title('Ideal Capacitor: Current Leads Voltage by 90^\circ (i_C = C dv_C/dt)');
grid on;

4. Part II: Interactive Phasor Bench (compass Polar & quiver Tip-to-Tail KVL)

By Euler’s formula (e^{j\theta} = \cos\theta + j\sin\theta), differentiating a sinusoid in the time domain is equivalent to multiplying its complex phasor by j\omega in the frequency domain, while integrating is equivalent to dividing by j\omega:

\frac{d}{dt} \iff j\omega = \omega\angle +90^\circ \qquad \Bigg| \qquad \int dt \iff \frac{1}{j\omega} = -j\frac{1}{\omega} = \frac{1}{\omega}\angle -90^\circ

5. Part III: What is Simulink & How Does It Model Circuits Visually?

Why Engineers Use Simulink Alongside MATLAB

While MATLAB executes sequential lines of text code, Simulink is a graphical block-diagram environment designed for modeling dynamical systems governed by differential equations. Instead of solving differential equations by hand before coding, Simulink allows students to wire mathematical operations (Sum, Gain, and Integrator 1/s blocks) directly into a closed-loop feedback system:

  1. The Integrator Block (\frac{1}{s}) as a Calculus Engine: In Laplace notation, multiplying by \frac{1}{s} represents time integration (\int dt). If the wire entering an Integrator block carries the derivative \frac{dv_C}{dt}, the wire exiting that block carries the integrated state variable v_C(t) itself.
  2. Isolate the Highest Derivative: For a 1st-order Series RC circuit (V_s = RC\frac{dv_C}{dt} + v_C), isolating the derivative yields: \frac{dv_C}{dt} = \frac{1}{RC}\Big[V_s(t) - v_C(t)\Big]
SIMULINK SCHEMATIC 1: 1ST-ORDER RC CHARGING INTEGRATOR LOOP — dv_C/dt = (1/RC)[V_s(t) − v_C(t)]
SIMULINK SCHEMATIC 2: 2ND-ORDER SERIES RLC TWO-INTEGRATOR ARCHITECTURE — di/dt = (1/L)[V_s − R·i(t) − v_C(t)]

Absolute Beginner’s Guide to MATLAB & .m Files

While single calculations in the Command Window disappear when MATLAB closes, sequences of commands saved in an .m Script File create reproducible engineering simulations.

  1. Create Your Script: Click New Script on the HOME ribbon and save as Circuit_Lab_LastName.m (use only letters, numbers, and underscores).
  2. Four Essential MATLAB Symbols:
    • % (Comment): Ignored by MATLAB; used to document engineering units.
    • ; (Semicolon): Suppresses screen printing of 5,000-element arrays.
    • : (Colon Operator): Generates evenly spaced time arrays (t = 0 : 1e-5 : 0.05;).
    • 1j (Imaginary Unit): Represents \sqrt{-1} = 1\angle +90^\circ for complex impedance calculations.

R = 30; L = 0.100;              % R = 30 Ohms, L = 100 mH

ZR = R;
