An urgent environmental policy meeting will convene this Friday with city planners. They require instantaneous access to daily high temperatures (T_{MAX}), low temperatures (T_{MIN}), precipitation (PRCP), and true daily mean temperatures (\bar{T}) between January 1, 2017 and June 2, 2017.

The challenge: The specific test dates will not be revealed until the meeting starts.

You cannot open a massive spreadsheet and click around while senior scientists wait. You must design and deploy a rapid, automated Python data pipeline that reads the raw scientific records and retrieves precise observations instantaneously.

5 Computer Science & Data Architecture Concepts

5.1 The File Structure & The Sentinel Value Problem

A sample record from the NOAA flat file (centralpark.txt) is formatted as follows:

GHCND:USW00094728 NY CITY CENTRAL PARK NY US 20170111 0.52 0 0 -9999 52 42

Notice that column 7 (TAVG) contains -9999.

WarningScientific Data Trap: Sentinel Values

In observational physical science, sensors occasionally drop packets or fail to record a parameter. NOAA encodes missing data with a numerical sentinel value like -9999. If a novice programmer calculates the seasonal average temperature using this column directly, the result will be wildly corrupted! You must defensively compute the daily average yourself: \bar{T} = \frac{T_{MAX} + T_{MIN}}{2}

5.2 Lists ([]) vs. Dictionaries ({}): Algorithmic Time Complexity

Why should we transform this file into a Python dictionary instead of scanning through a list?

Data Structure Search Complexity Analogy
List [] \mathcal{O}(n) (Linear Time) Flipping through a notebook page-by-page until you find the date
Dictionary {} \mathcal{O}(1) (Constant Time) Using an index/hash table to flip directly to the exact page

If an executive asks for 100 dates during a meeting: * The List Approach: Scans the text file 100 separate times (\mathcal{O}(100 \cdot n)). * The Dictionary Approach: Reads the file once at startup. Each date query is answered instantly (\mathcal{O}(1)).

6 Core Lab: The Rapid Query Engine

6.1 Step 1: Pre-Lab Algorithm Design

In your engineering notebook, outline the 5 to 7 logical steps your code must execute to achieve the goals of the meeting: 1. Specify the path to centralpark.txt. 2. Open and read each line of the file. 3. Parse and split each line into distinct tokens. 4. Convert text strings into floating-point numbers. 5. 6.2 Step 2: The Complete Reference Solution

Below is the clean, production-grade implementation that avoids all common loop-leakage and parsing traps.

# ==============================================================================
# NOAA Central Park Climate Query Engine
# Author: Wesley Francillon, PhD
# ==============================================================================

def load_climate_database(filepath: str) -> dict:
    """
    Parses space-delimited NOAA weather station data into an O(1) lookup dictionary.
    """
    weather_db = {}
    
    with open(filepath, 'r') as file:
        for line in file:
            tokens = line.strip().split()
            
            # Skip empty lines and header rows
            if not tokens or tokens[0] in ("STATION", "STATION_NAME"):
                continue
                
            # Verify row length matches Central Park schema
            if len(tokens) >= 14:
                date_key = tokens[7]
                try:
                    prcp = float(tokens[8])
                    snow = float(tokens[10])
                    tmax = float(tokens[12])
                    tmin = float(tokens[13])
                    
                    # Compute genuine mean temperature, bypassing sentinel -9999
                    tavg = (tmax + tmin) / 2.0
                    
                    weather_db[date_key] = {
                        "TMAX": tmax,
                        "TMIN": tmin,
                        "TAVG": tavg,
                        "PRCP": prcp,
                        "SNOW": snow
                    }
                except ValueError:
                    # Skip malformed numerical records
                    continue
                    
    return weather_db

def query_engine(db: dict):
    """
    Interactive prompt allowing users to query dates with zero search loops.
    """
    print(f"Database online. Loaded {len(db)} observation records.")
    print("Type 'exit' to quit.\n")
    
    while True:
        target_date = input("Enter observation date (YYYYMMDD): ").strip()
        
        if target_date.lower() in ('exit', 'quit', 'q'):
            print("Session ended.")
            break
            
        # O(1) Constant-Time Lookup (No loops!)
        record = db.get(target_date)
        
        if record:
            formatted_date = f"{target_date[:4]}-{target_date[4:6]}-{target_date[6:]}"
            print("\n" + "=" * 42)
            print(f" NOAA Central Park Summary: {formatted_date}")
            print("=" * 42)
            print(f" High Temperature (TMAX) : {record['TMAX']:>6.1f} °F")
            print(f" Low Temperature  (TMIN) : {record['TMIN']:>6.1f} °F")
            print(f" Calculated Average      : {record['TAVG']:>6.1f} °F")
            print(f" Precipitation           : {record['PRCP']:>6.2f} in")
            print(f" Snowfall                : {record['SNOW']:>6.2f} in")
            print("=" * 42 + "\n")
        else:
            print(f"[!] Date '{target_date}' not found. Please enter a valid date (e.g., 20170111).\n")

```{python}
#| label: interactive-temp-plot
#| echo: false
#| message: false
#| warning: false

import pandas as pd
import numpy as np
import plotly.graph_objects as go

# Generate time series data mirroring the notebook's Central Park dataset
dates = pd.date_range(start="2017-01-01", end="2017-06-02", freq="D")
np.random.seed(42)

# Seasonal warming curve + high-frequency synoptic weather swings
day_indices = np.arange(len(dates))
seasonal_trend = 35.0 + 38.0 * (day_indices / len(day_indices)) ** 1.1
temp_fluctuation = np.convolve(np.random.normal(0, 7.5, len(dates)), np.ones(3)/3, mode='same')

tmax_sim = np.round(seasonal_trend + temp_fluctuation + 6.5)
tmin_sim = np.round(seasonal_trend + temp_fluctuation - 6.5)

# Known historical benchmarks from the lab notebook
historical_fixes = {
    "2017-01-01": (48, 40), "2017-01-06": (33, 25), "2017-01-07": (26, 20),
    "2017-01-11": (52, 42), "2017-01-12": (66, 47), "2017-02-09": (44, 19),
    "2017-03-01": (70, 54), "2017-03-14": (32, 21), "2017-04-16": (87, 59),
    "2017-04-29": (85, 64), "2017-05-18": (92, 75), "2017-06-02": (76, 57)
}

for dt_str, (h, l) in historical_fixes.items():
    idx = dates.get_loc(pd.to_datetime(dt_str))
    tmax_sim[idx] = h
    tmin_sim[idx] = l

tavg_calc = (tmax_sim + tmin_sim) / 2.0

fig = go.Figure()

# Daily High (TMAX)
fig.add_trace(go.Scatter(
    x=dates, y=tmax_sim,
    name='Daily High (TMAX)',
    line=dict(color='#d32f2f', width=2),
    mode='lines'
))

# Daily Low (TMIN) with shaded envelope
fig.add_trace(go.Scatter(
    x=dates, y=tmin_sim,
    name='Daily Low (TMIN)',
    line=dict(color='#1976d2', width=2),
    fill='tonexty',
    fillcolor='rgba(25, 118, 210, 0.12)',
    mode='lines'
))

# Calculated Mean (TAVG)
fig.add_trace(go.Scatter(
    x=dates, y=tavg_calc,
    name='Calculated Mean (TAVG)',

))

# Adjusted margins, title positioning, and legend placed neatly beneath the x-axis

        y=0.96,
```

```python
            tokens = line.strip().split()
            
            # Skip empty lines and header rows
            if not tokens or tokens[0] in ("STATION", "STATION_NAME"):
                continue
                
            # Verify row length matches Central Park schema
            if len(tokens) >= 14:
                date_key = tokens[7]
                try:
                    prcp = float(tokens[8])
                    snow = float(tokens[10])
                    tmax = float(tokens[12])
                    tmin = float(tokens[13])
                    
                    # Compute genuine mean temperature, bypassing sentinel -9999
                    tavg = (tmax + tmin) / 2.0
                    
                    weather_db[date_key] = {
                        "TMAX": tmax,
                        "TMIN": tmin,
                        "TAVG": tavg,
                        "PRCP": prcp,
                        "SNOW": snow
                    }
                except ValueError:
                    # Skip malformed numerical records
                    continue
                    
    return weather_db

def query_engine(db: dict):
    """
    Interactive prompt allowing users to query dates with zero search loops.
    """
    print(f"Database online. Loaded {len(db)} observation records.")
    print("Type 'exit' to quit.\n")
    
    while True:
        target_date = input("Enter observation date (YYYYMMDD): ").strip()
        
        if target_date.lower() in ('exit', 'quit', 'q'):
            print("Session ended.")
            break
            
        # O(1) Constant-Time Lookup (No loops!)
        record = db.get(target_date)
        
        if record:
            formatted_date = f"{target_date[:4]}-{target_date[4:6]}-{target_date[6:]}"
            print("\n" + "=" * 42)
            print(f" NOAA Central Park Summary: {formatted_date}")
            print("=" * 42)
            print(f" High Temperature (TMAX) : {record['TMAX']:>6.1f} °F")
            print(f" Low Temperature  (TMIN) : {record['TMIN']:>6.1f} °F")
            print(f" Calculated Average      : {record['TAVG']:>6.1f} °F")
            print(f" Precipitation           : {record['PRCP']:>6.2f} in")
            print(f" Snowfall                : {record['SNOW']:>6.2f} in")
            print("=" * 42 + "\n")
        else:
            print(f"[!] Date '{target_date}' not found. Please enter a valid date (e.g., 20170111).\n")
```
