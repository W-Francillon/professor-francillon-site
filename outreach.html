K-12 STEM OUTREACH & DISCOVERY LABS

Interactive, Hands-On Engineering, Physics, Materials Science & Data Science Modules

Tier 1: Foundations & Exploratory STEM

Target Audience: Grades 6–9 (Middle School to Early High School)  |  Core Concepts: Physical intuition, environmental signals, wave matching, and introductory electronics.

Grades 6–9 • Physics & RF

RF Fox Hunt Lab

Locate hidden wireless transmitters using Received Signal Strength Indicator (RSSI) telemetry, inverse-square law attenuation, and directional trilateration.

Launch Lab

Grades 6–9 • Earth & Data Science

Fishing Tide Predictor

Fetch live NOAA ocean water-level predictions via API, map local coastal stations, and model harmonic lunar/solar tidal cycles along Long Island Sound.

Launch Module

Grades 6–9 • Interactive Game

Resonance Defender Game

Gamified RLC tuning simulation where students dynamically adjust inductance and capacitance to lock onto incoming frequencies and maximize power transfer.

Play Game

Grades 6–9 • Interactive Game

Impedance Breaker Game

Arcade-style engineering challenge combining brick-breaker physics with passive component identification, circuit simplification, and impedance matching.

Play Game

Tier 2: Applied Data Science & Predictive Modeling

Target Audience: Grades 9–11 (High School STEM & AP Prep)  |  Core Concepts: Least-squares regression, API data pipelines, automated web scraping, and environmental telemetry.

Grades 9–11 • Machine Learning

Linear Regression Modeling

Build foundational predictive models using ordinary least squares (OLS), evaluate R^2 goodness-of-fit, and visualize residual error distributions in Python.

Open Module

Grades 9–11 • Climate Analytics

Vehicle CO2 Emissions Regression

Analyze real-world automotive telemetry datasets to model how engine displacement, cylinder count, and fuel consumption drive tailpipe \text{CO}_2 emissions.

Open Module

Grades 9–11 • Data Engineering

API Data Challenge

Query live public REST endpoints, parse nested JSON payloads into Pandas DataFrames, and automate real-time scientific data visualizations.

Open Challenge

Grades 9–11 • Python Automation

Scientific Web Scraping

Extract structured tabular datasets from HTML DOM trees using BeautifulSoup, clean noisy text records, and prepare reproducible analysis pipelines.

Open Module

Tier 3: Advanced Materials Science & Honors Engineering

Target Audience: Grades 11–12 & Undergraduate Bridge (Honors / AP Physics & Chemistry)  |  Core Concepts: X-ray diffraction (Bragg’s Law), solid-state crystallography, and planetary mineralogy.

Grades 11–12 • Planetary Materials

Mars Rover XRD Mineralogy Lab

Apply Bragg’s Law (n\lambda = 2d\sin\theta) to authentic Curiosity Rover CheMin X-ray diffraction spectra to identify crystalline minerals in Martian soil.

Launch Lab

Grades 11–12 • Solid-State Physics

3D Crystal Structures & Unit Cells

Explore Simple Cubic (SC), Body-Centered Cubic (BCC), and Face-Centered Cubic (FCC) lattices, coordination numbers, and atomic packing factors.
