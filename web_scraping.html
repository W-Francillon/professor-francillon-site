Automating the Web: Web Scraping Projects

HTML Parsing, Binary Downloads, and Data Extraction with Python

Author

Dr. Wesley Francillon

Note🚀 Welcome to the Papillon Engineering K-12 Outreach Hub

This module introduces students to the fundamentals of web scraping and automation. By automating the process of navigating web pages, locating specific HTML elements, downloading binary files, and parsing text into logic, you will learn how Python scripts interact with the modern web.

Project 1: The Automated Webcomic Downloader

This project challenges you to build a functional web scraper that navigates the popular webcomic XKCD, extracts the daily comic, downloads the image file, and repeats the process automatically.

  • 💻 Student Interactive Workbook
  • 👨‍🏫 Instructor Facilitation Guide

Introduction: Your Python Superpower

Imagine you want to download a picture from a website. You right-click, select “Save As”, and pick a folder. Easy, right? But what if you want to download every single picture from a website that has thousands of pages? Doing that by hand would take days.

Today, you are going to write a Python script that acts like an automated robot. It will visit the popular webcomic XKCD, find the daily comic, download it, click the “Previous” button, and do it all over again automatically.

Step 1: Setting up our Robot

We need three special tools for this job: requests (to browse the web), bs4 / BeautifulSoup (to read the website’s code), and os (to create folders on your computer).

#| eval: false
import requests, os, bs4

url = 'https://xkcd.com'               # The starting URL
os.makedirs('xkcd', exist_ok=True)     # Create a folder called 'xkcd' to store our images

Step 2: Fetching the Web Page

We will use a while loop to tell our robot to keep working. For this practice run, we will limit it to downloading just 5 comics so we don’t overload our network!

#| eval: false
comics_to_download = 5
count = 0

while not url.endswith('#') and count < comics_to_download:
    print(f'Downloading page {url}...')
    res = requests.get(url)
    res.raise_for_status() # This checks if the webpage actually loaded successfully
    
    # Translate the webpage text into readable HTML
    soup = bs4.BeautifulSoup(res.text, 'html.parser')

Step 3: Finding the Image

A web page is full of code. We need to tell our robot exactly where the comic is. If you right-click and “Inspect” the XKCD website, you will see the comic is always inside an HTML ID called comic, inside an img tag.

#| eval: false
    # Locate the image using a CSS Selector
    comicElem = soup.select('#comic img')
    
    if comicElem == []:
        print('Could not find comic image.')
    else:
        # Extract the image source URL
        comicUrl = 'https:' + comicElem[0].get('src')
        print(f'Found image at {comicUrl}... Downloading!')
        
        # Download the actual image file
        res = requests.get(comicUrl)
        res.raise_for_status()

Step 4: Saving the File (Binary Data)

Images aren’t text; they are “binary” data (1s and 0s). We need to open a file in “write binary” (wb) mode and save the image in small chunks so we don’t crash our computer’s memory.

#| eval: false
        # Create the file on your hard drive
        imageFile = open(os.path.join('xkcd', os.path.basename(comicUrl)), 'wb')
        
        # Save it in 100,000-byte chunks
        for chunk in res.iter_content(100000):
            imageFile.write(chunk)
        imageFile.close()

Step 5: Traveling Back in Time

If we stop here, our robot will just download today’s comic over and over forever! We need to find the “Prev” (Previous) button on the webpage, grab its link, and tell our robot to go there next.

#| eval: false
    # Find the "Previous" button link
    prevLink = soup.select('a[rel="prev"]')[0]
    
    # Update our main URL variable to the new page!
    url = 'https://xkcd.com' + prevLink.get('href')
    
    count += 1 # Increase our counter

print('Done! Check the new /xkcd folder on your computer.')

1. Module Overview & Learning Objectives

Core Learning Objectives: - Network Requests: Use the requests library to fetch HTML from a live URL. - HTML Parsing: Use BeautifulSoup (bs4) to navigate the Document Object Model (DOM) and extract specific elements using CSS selectors. - File I/O: Learn how to create directories and write binary data in chunks to save images locally. - Algorithmic Loops: Implement a while loop that dynamically updates its target URL to navigate backward through web pages.

2. Materials & Prerequisites

  • Software Environment: Python 3.x installed with the requests and beautifulsoup4 packages.
  • Platform: Quarto-rendered web pages hosted via Papillon Engineering or local Jupyter Notebooks.
  • Prior Knowledge: Basic understanding of HTML tags (<img>, <a>, id, href), Python while loops, and file paths.

3. Common Pitfalls & Instructor Key

If students attempt to run the original loop without updating the url variable at the end of the block, they will trigger an infinite loop, locking up their Python environment by downloading the same comic continuously.

Additionally, downloading all 3,000+ XKCD comics on a school network could trigger bandwidth throttles. The solution below includes a comics_to_download safety counter.

The Completed Solution Code:

#| eval: false
import requests, os, bs4

url = 'https://xkcd.com'               
os.makedirs('xkcd', exist_ok=True)    

comics_to_download = 5 # Safety limit for the classroom
count = 0

while not url.endswith('#') and count < comics_to_download:
    print(f'Downloading page {url}...')
    res = requests.get(url)
    res.raise_for_status()
    soup = bs4.BeautifulSoup(res.text, 'html.parser')

    comicElem = soup.select('#comic img')
    if comicElem == []:
        print('Could not find comic image.')
    else:
        comicUrl = 'https:' + comicElem[0].get('src')
        print(f'Downloading image {comicUrl}...')
        res = requests.get(comicUrl)
        res.raise_for_status()

        imageFile = open(os.path.join('xkcd', os.path.basename(comicUrl)), 'wb')
        for chunk in res.iter_content(100000):
            imageFile.write(chunk)
        imageFile.close()

    prevLink = soup.select('a[rel="prev"]')[0]
    url = 'https://xkcd.com' + prevLink.get('href')
    count += 1

print('Done! Check your /xkcd folder.')


Project 2: Automated Hardware Price Tracker

While the XKCD bot downloads files, many engineers use web scraping to monitor data that changes constantly—like the price of a graphics card, micro-controller, or 3D printer.

In this project, we use BeautifulSoup to scrape a product page, locate the exact HTML <span> containing the price, convert that text into a math-ready number, and write logic to alert us if the price drops below our budget!

  • ⚙️ How to Take it Further
  • 💻 The Price Tracker Script

Right now, the script (see next tab) runs once and stops. How can you make it a true automated tracker?

Warning1. The Infinite Loop (with a pause)

Wrap the check_price function in a while True: loop, but add time.sleep(86400) so the script waits 24 hours between checks instead of spamming the server.

Tip2. Email Alerts

Research the Python smtplib library. You can program your script to automatically send an email to your phone the second the price drops below your budget!

Note3. Transitioning to RSS Feeds

HTML scraping breaks easily if the store updates its website design or changes its CSS classes. For a more robust, professional way to gather data, proceed to the Automated Engineering Wire Lab to learn how data engineers use XML Syndication (RSS) instead of HTML scraping!

For this example, we will simulate scraping an electronics storefront for a Raspberry Pi 5. Websites often hide prices inside specific CSS classes, like <span class="price-display">$79.99</span>.

#| eval: false
import requests
import bs4
import time

def check_price(url, target_price):
    print(f"Scanning {url}...")
    
    # 1. Fetch the webpage
    # Note: Many stores block Python scripts. Adding 'headers' makes us look like a real browser!
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
    }
    res = requests.get(url, headers=headers)
    res.raise_for_status()
    
    # 2. Parse the HTML
    soup = bs4.BeautifulSoup(res.text, 'html.parser')
    
    # 3. Locate the price element
    # (You would find this exact CSS selector by right-clicking and Inspecting the store page)
    price_element = soup.select('.price-display, .a-price-whole')
    
    if not price_element:
        print("Error: Could not locate the price on the page.")
        return
        
    # 4. Clean the data (Convert "$79.99" to 79.99)
    raw_price_text = price_element[0].get_text()
    
    # Strip out the dollar sign and any commas
    clean_text = raw_price_text.replace('$', '').replace(',', '').strip()
    current_price = float(clean_text)
    
    print(f"Current Price: ${current_price:.2f}")
    
    # 5. Logic Check
    if current_price <= target_price:
        print("🚨 DEAL ALERT! The price has dropped below your budget! Buy it now!")
        # In a real app, you could add code here to send yourself an email or SMS
    else:
        print(f"Still too expensive. It needs to drop by ${current_price - target_price:.2f}.")

if __name__ == "__main__":
    PRODUCT_URL = "https://example-electronics-store.com/raspberry-pi-5"
    MY_BUDGET = 65.00
    
    # Run the scanner
    check_price(PRODUCT_URL, MY_BUDGET)
